Antes de transformar qualquer coisa, vale entender o que a equação diferencial está dizendo.

A transformada de Laplace só é útil porque uma classe enorme de problemas de circuitos é descrita por equações diferenciais ordinárias. Esse módulo é o pré-requisito: o que é uma EDO, por que a ordem importa, como as condições iniciais entram, o que caracteriza um sistema de segunda ordem e por que a gente insiste em avaliar tudo em \(0^-\). Nada de transformada aqui — só o terreno. A ferramenta em si começa no módulo 01.

0.1

O que é uma equação diferencial ordinária

Uma EDO é uma relação envolvendo uma função desconhecida de uma única variável independente e uma ou mais de suas derivadas. Usando \(t\) como variável independente e \(x(t)\) como função desconhecida, uma EDO de ordem \(n\) pode ser escrita genericamente como:

\[ \Phi\big(t,\,x,\,\dot x,\,\ddot x,\,\ldots,\,x^{(n)}\big) = 0 \]

A ordem é dada pela derivada de maior ordem presente na equação. Por exemplo, \(\dot x + 3x = u(t)\) é de primeira ordem, enquanto \(\ddot x + 5\dot x + 6x = u(t)\) é de segunda.

No escopo deste curso interessa principalmente a classe das EDOs lineares com coeficientes constantes:

\[ a_n\,x^{(n)}(t) + a_{n-1}\,x^{(n-1)}(t) + \cdots + a_1\,\dot x(t) + a_0\,x(t) = r(t), \qquad a_n \ne 0 \]

Os coeficientes \(a_k\) são constantes e \(r(t)\) é uma função conhecida — chamada de excitação, termo forçante ou segundo membro.

É linear

\(x\) e suas derivadas aparecem apenas na primeira potência e não são multiplicadas entre si:

\(\ddot x + 2\dot x + 5x = r(t)\)

Não é linear

Aqui há produto entre \(x\) e \(\dot x\), ou potência de \(x\):

\(\ddot x + x\dot x + 5x = r(t)\)  ·  \(\ddot x + x^2 = r(t)\)

Linearidade e superposição — definindo o operador \(\mathcal{D}[x] = a_n x^{(n)} + \cdots + a_1\dot x + a_0 x\), vale
\[ \mathcal{D}[\lambda_1 x_1 + \lambda_2 x_2] = \lambda_1\,\mathcal{D}[x_1] + \lambda_2\,\mathcal{D}[x_2] \]
É exatamente essa estrutura que permite separar a resposta em parcelas associadas às condições iniciais e à excitação — e, mais adiante, é o que garante a linearidade da própria transformada de Laplace.
0.2

Equação homogênea, solução particular e solução completa

Quando o segundo membro é nulo, \(a_n x^{(n)} + a_{n-1}x^{(n-1)} + \cdots + a_0 x = 0\), a equação é chamada homogênea. Quando \(r(t) \ne 0\), ela é não homogênea.

Para uma EDO linear, qualquer solução completa pode ser escrita como:

\[ x(t) = x_h(t) + x_p(t) \]
\(x_h(t)\) — parcela homogênea

É uma solução da equação homogênea associada. É ela que contém as constantes livres determinadas pelas condições iniciais. Em circuitos, corresponde à parcela transitória.

\(x_p(t)\) — solução particular

Depende da excitação. Quando a excitação é senoidal e o sistema é estável, \(x_p\) coincide com a resposta de regime permanente senoidal obtida por fasores.

Essa separação é exatamente a mesma usada no material de circuitos de segunda ordem. A transformada de Laplace vai reorganizar essas etapas — não substituí-las por outra física.
0.3

Equação característica e a forma da solução homogênea

Para EDOs lineares com coeficientes constantes, procura-se uma solução elementar da forma \(x_h(t) = e^{\lambda t}\). Como \(x_h^{(k)}(t) = \lambda^k e^{\lambda t}\), a substituição na equação homogênea fornece:

\[ \big(a_n\lambda^n + a_{n-1}\lambda^{n-1} + \cdots + a_1\lambda + a_0\big)\,e^{\lambda t} = 0 \]

Como \(e^{\lambda t} \ne 0\) para qualquer \(t\), resta a equação característica:

\[ a_n\lambda^n + a_{n-1}\lambda^{n-1} + \cdots + a_1\lambda + a_0 = 0 \]

São as raízes dessa equação que determinam a forma da solução homogênea:

Raízes reais distintas

Se \(\lambda_1,\ldots,\lambda_n\) são todas distintas:

\[ x_h(t) = C_1 e^{\lambda_1 t} + \cdots + C_n e^{\lambda_n t} \]
Raiz real repetida

Se \(\lambda\) possui multiplicidade \(m\), sua contribuição é:

\[ \big(C_0 + C_1 t + \cdots + C_{m-1}t^{\,m-1}\big)e^{\lambda t} \]
Par complexo conjugado

Para coeficientes reais, raízes complexas aparecem aos pares \(\alpha \pm j\beta\). A contribuição pode ser escrita de forma real como:

\[ e^{\alpha t}\big(C_1\cos\beta t + C_2\,\mathrm{sen}\,\beta t\big) \]
Guarde isso — vai voltar. Essas mesmas três estruturas reaparecem literalmente na antitransformação de funções racionais: polos simples geram exponenciais, polos repetidos acrescentam potências de \(t\) e pares conjugados geram senoides amortecidas. Aqui estamos só estabelecendo a conexão algébrica com a solução da EDO — a versão em \(s\) está no módulo 03.
0.4

Problema de valor inicial

Uma EDO de ordem \(n\) não determina, sozinha, uma única função. A solução geral possui \(n\) constantes independentes; para selecionar uma solução específica, são necessários \(n\) dados independentes.

Quando esses dados são fornecidos todos em um mesmo instante \(t = t_0\), temos um problema de valor inicial (PVI):

\[ \begin{cases} a_n x^{(n)} + \cdots + a_0 x = r(t), \\[4pt] x(t_0) = x_0, \\[2pt] \dot x(t_0) = x_1, \\[2pt] \quad\vdots \\[2pt] x^{(n-1)}(t_0) = x_{n-1}. \end{cases} \]
Ordem da EDO e número de dados iniciais — em geral, uma EDO de ordem \(n\) requer \(n\) condições iniciais independentes. Uma EDO de segunda ordem exige dois dados, tipicamente \(x(0)\) e \(\dot x(0)\). Em circuitos, esses dois dados costumam ser obtidos a partir das variáveis de energia (tensão no capacitor, corrente no indutor) e das equações de Kirchhoff.
0.5

Por que aparecem os valores em \(0^-\)

Em problemas de chaveamento e excitações impulsivas pode existir diferença entre o valor imediatamente antes da origem e o valor imediatamente depois dela. Por isso distinguimos:

\[ x(0^-) = \lim_{t\to 0^-} x(t), \qquad x(0^+) = \lim_{t\to 0^+} x(t) \]

Na transformada de Laplace unilateral, \(0^-\) é particularmente conveniente porque representa o estado conhecido imediatamente antes da ação aplicada em \(t=0\).

Mas atenção: nem toda variável pode sofrer um salto arbitrário. Isso depende da EDO e da presença ou não de termos singulares. Considere:

Quanto vale o salto? — derivação em um intervalo infinitesimal
\(\dot x(t) + a\,x(t) = K\,\delta(t)\) integra os dois lados em um intervalo infinitesimal ao redor de \(t=0\): \(\displaystyle \int_{0^-}^{0^+}\dot x\,dt + a\int_{0^-}^{0^+} x\,dt = K\int_{0^-}^{0^+}\delta(t)\,dt\) a integral de uma função limitada sobre um intervalo de largura tendendo a zero desaparece — então o termo do meio morre já a integral do impulso vale 1 (é a definição dele), e a do lado esquerdo é a variação de \(x\): \(x(0^+) - x(0^-) = K\)
\(x(0^+) = x(0^-) + K\) — o impulso força um salto de altura exatamente \(K\)
Esse exemplo pequeno mostra por que a distinção entre \(0^-\) e \(0^+\) não é apenas notacional. Se não houver impulso na excitação, os dois valores coincidem e você pode usar o que preferir; se houver, eles diferem — e a transformada unilateral, começando em \(0^-\), usa o valor antes do chaveamento.
0.6

A forma normalizada de uma EDO de segunda ordem

A forma canônica utilizada neste curso é:

\[ \ddot x(t) + 2\alpha\,\dot x(t) + \omega_0^2\,x(t) = x_s(t) \]

Os parâmetros \(\alpha\) (fator de amortecimento) e \(\omega_0\) (frequência natural) são definidos a partir dos coeficientes da EDO. A equação homogênea associada é \(\ddot x + 2\alpha\dot x + \omega_0^2 x = 0\), cuja equação característica é:

\[ \lambda^2 + 2\alpha\lambda + \omega_0^2 = 0 \]

Pela fórmula de Bhaskara:

\[ \lambda_{1,2} = \frac{-2\alpha \pm \sqrt{(2\alpha)^2 - 4\omega_0^2}}{2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2} \]

No material de circuitos de segunda ordem, essas raízes são também chamadas frequências complexas próprias. Aqui vamos usá-las apenas como raízes da equação característica; a interpretação delas como propriedade de rede fica para o documento de Funções de Rede.

0.7

Solução geral para raízes distintas

Se \(\lambda_1 \ne \lambda_2\), a solução completa é \(x(t) = X_1 e^{\lambda_1 t} + X_2 e^{\lambda_2 t} + x_p(t)\). Derivando, \(\dot x(t) = \lambda_1 X_1 e^{\lambda_1 t} + \lambda_2 X_2 e^{\lambda_2 t} + \dot x_p(t)\). Em \(t=0\):

\[ X_1 + X_2 = x(0) - x_p(0), \qquad \lambda_1 X_1 + \lambda_2 X_2 = \dot x(0) - \dot x_p(0) \]

É útil definir as duas condições iniciais líquidas — isto é, já descontada a parcela particular:

\[ a \equiv x(0) - x_p(0), \qquad b \equiv \dot x(0) - \dot x_p(0) \]

Assim o sistema fica:

\[ \begin{bmatrix} 1 & 1 \\ \lambda_1 & \lambda_2 \end{bmatrix}\begin{bmatrix} X_1 \\ X_2 \end{bmatrix} = \begin{bmatrix} a \\ b \end{bmatrix} \;\Longrightarrow\; X_1 = \frac{\lambda_2 a - b}{\lambda_2 - \lambda_1}, \quad X_2 = \frac{b - \lambda_1 a}{\lambda_2 - \lambda_1} \]
\[ x(t) = \frac{\lambda_2 a - b}{\lambda_2 - \lambda_1}\,e^{\lambda_1 t} + \frac{b - \lambda_1 a}{\lambda_2 - \lambda_1}\,e^{\lambda_2 t} + x_p(t) \]

Essa expressão é geral para raízes distintas e é uma forma compacta de incorporar as condições iniciais. Note que \(a\) e \(b\) fazem todo o trabalho: o resto é só a dinâmica da rede.

0.8

Os três regimes de uma EDO de segunda ordem

A natureza das raízes depende da comparação entre \(\alpha\) e \(\omega_0\) — ou, equivalentemente, do sinal de \(\alpha^2 - \omega_0^2\).

1 · Superamortecimento  \(\alpha > \omega_0\)

Definindo \(\beta = \sqrt{\alpha^2 - \omega_0^2} > 0\), tem-se \(\lambda_{1,2} = -\alpha \pm \beta\): duas raízes reais distintas. A resposta transitória é uma soma de duas exponenciais reais decrescentes (quando \(\alpha>0\)).

A solução também pode ser reorganizada em funções hiperbólicas:

\[ x(t) = e^{-\alpha t}\!\left[a\cosh(\beta t) + \frac{\alpha a + b}{\beta}\,\mathrm{senh}(\beta t)\right] + x_p(t) \]

Isso é apenas uma reescrita da soma das duas exponenciais — pode ser conveniente em alguns cálculos, e é a razão pela qual \(\cosh\) e \(\mathrm{senh}\) aparecem na tabela de transformadas.

2 · Subamortecimento  \(\alpha < \omega_0\)

Define-se a frequência amortecida \(\omega_d = \sqrt{\omega_0^2 - \alpha^2}\), e as raízes passam a ser \(\lambda_{1,2} = -\alpha \pm j\omega_d\).

Como os coeficientes da EDO e as condições iniciais são reais, as constantes associadas às duas exponenciais complexas são conjugadas. Ao recombinar os termos, a solução real fica:

\[ x(t) = e^{-\alpha t}\!\left[a\cos(\omega_d t) + \frac{\alpha a + b}{\omega_d}\,\mathrm{sen}(\omega_d t)\right] + x_p(t) \]

Vale ler essa expressão com atenção: \(e^{-\alpha t}\) controla o envelope de decaimento; \(\omega_d\) controla a oscilação observada durante o transitório; e \(a\), \(b\) incorporam as condições iniciais depois de retirar a parcela particular.

A mesma parcela oscilatória pode ser condensada em uma única cossenoide, \(X e^{-\alpha t}\cos(\omega_d t + \psi)\), porque qualquer combinação \(A\cos\omega_d t + B\,\mathrm{sen}\,\omega_d t\) tem amplitude e fase equivalentes.

3 · Amortecimento crítico  \(\alpha = \omega_0\)

As raízes coincidem: \(\lambda_1 = \lambda_2 = -\alpha\). A segunda solução independente não pode ser outra cópia de \(e^{-\alpha t}\) — ela deve ser \(t\,e^{-\alpha t}\). Assim:

\[ x(t) = X_1 e^{-\alpha t} + X_2\,t\,e^{-\alpha t} + x_p(t) \]

Aplicando as condições iniciais, \(X_1 = a\) e \(X_2 = b + \alpha a\), logo:

\[ x(t) = e^{-\alpha t}\big[a + (b+\alpha a)\,t\big] + x_p(t) \]
Uma mesma EDO em três aparências temporais. A ordem continua sendo dois em todos os casos. O que muda é apenas a natureza das raízes da mesma equação característica: duas raízes reais distintas, um par complexo conjugado ou uma raiz real dupla. O tratamento completo desses três casos aplicado ao RLC paralelo está no módulo 05.
0.9

Como obter as condições iniciais em circuitos

Uma dificuldade recorrente é saber de onde tirar \(x(0)\) e \(\dot x(0)\). A regra prática é simples: procure a equação constitutiva que contém a derivada desejada.

Capacitor

\(\displaystyle i_C(t) = C\,\frac{dv_C}{dt}\)

Logo, uma derivada de tensão pode ser determinada pela corrente do capacitor no instante inicial.

Indutor

\(\displaystyle v_L(t) = L\,\frac{di_L}{dt}\)

Logo, uma derivada de corrente pode ser determinada pela tensão no indutor naquele instante.

A "fotografia" de \(t = 0^+\) — para calcular uma derivada inicial, determine primeiro as grandezas contínuas associadas aos elementos armazenadores (\(v_C\) e \(i_L\)) e então aplique Kirchhoff no circuito imediatamente após a comutação. Em outras palavras: localize onde aparece a derivada desejada e calcule a corrente ou tensão correspondente naquele instante.
0.10

Exemplo completo: RCC de segunda ordem com dois capacitores

A fonte de corrente \(i_s(t)\) alimenta três ramos em paralelo: um ramo \(R_1\)–\(C_1\) em série, um capacitor \(C_2\) e um resistor \(R_2\). Definimos \(v_1(t)\) como a tensão sobre \(C_1\) e \(v_2(t)\) como a tensão do nó superior — que também é a tensão sobre \(C_2\) e \(R_2\).

Incógnita: \(v_1(t)\) — tensão sobre \(C_1\) Variável auxiliar: \(v_2(t)\) — tensão do nó Excitação: \(i_s(t)\)
01
Equação do ramo R₁–C₁

A corrente que atravessa \(R_1\) é a mesma que entra em \(C_1\) — é um ramo série:

\[ C_1\dot v_1 = \frac{v_2 - v_1}{R_1} \;\Longrightarrow\; v_2 = v_1 + R_1 C_1 \dot v_1 \]
02
KCL no nó de tensão v₂

A corrente em \(C_2\) é \(C_2\dot v_2\). Tomando como positivas as correntes que entram no nó a partir da fonte e do ramo \(R_1\)–\(C_1\):

\[ C_2\dot v_2 = \frac{v_1 - v_2}{R_1} - \frac{v_2}{R_2} + i_s(t) \]
03
Eliminar a variável auxiliar v₂

Da relação do passo 01, \(v_2 = v_1 + R_1C_1\dot v_1\) e, derivando, \(\dot v_2 = \dot v_1 + R_1C_1\ddot v_1\). Substituindo ambos na KCL:

\[ C_2\big(\dot v_1 + R_1C_1\ddot v_1\big) = -C_1\dot v_1 - \frac{v_1}{R_2} - \frac{R_1C_1}{R_2}\dot v_1 + i_s(t) \]

Passando tudo para o primeiro membro:

\[ R_1C_1C_2\,\ddot v_1 + \left(C_2 + C_1 + \frac{R_1C_1}{R_2}\right)\dot v_1 + \frac{1}{R_2}v_1 = i_s(t) \]
04
Normalizar e identificar α e ω₀

Dividindo tudo por \(R_1C_1C_2\):

\[ \ddot v_1 + \left(\frac{1}{R_1C_2} + \frac{1}{R_2C_2} + \frac{1}{R_2C_1}\right)\dot v_1 + \frac{1}{R_1R_2C_1C_2}\,v_1 = \frac{i_s(t)}{R_1C_1C_2} \]

Comparando com \(\ddot x + 2\alpha\dot x + \omega_0^2 x = x_s(t)\):

\[ \alpha = \frac{1}{2}\left(\frac{1}{R_1C_2} + \frac{1}{R_2C_2} + \frac{1}{R_2C_1}\right), \qquad \omega_0^2 = \frac{1}{R_1R_2C_1C_2} \]
05
Condições iniciais — a segunda não vem de graça

A primeira é diretamente a tensão inicial do capacitor \(C_1\): \(v_1(0^+) = v_{10}\). Se não houver impulso de corrente que force um salto de tensão, \(v_{10} = v_1(0^-)\).

Para obter \(\dot v_1(0^+)\), usamos exatamente a equação em que essa derivada aparece — a do passo 01:

\[ C_1\dot v_1 = \frac{v_2 - v_1}{R_1} \;\Longrightarrow\; \dot v_1(0^+) = \frac{v_{20} - v_{10}}{R_1 C_1} \]

Essa passagem é importante: uma EDO de segunda ordem exige dois dados iniciais, mas eles não precisam ser fornecidos explicitamente no enunciado. Muitas vezes um deles é uma tensão ou corrente armazenada e o outro deve ser obtido das leis do circuito em \(t=0^+\).

06
Especializar para um degrau de corrente

Se \(i_s(t) = I_0 H(t)\), a solução particular constante sai impondo \(\dot v_1 = \ddot v_1 = 0\) na EDO:

\[ \frac{1}{R_1R_2C_1C_2}\,v_{1p} = \frac{I_0}{R_1C_1C_2} \;\Longrightarrow\; v_{1p} = I_0 R_2 \]

Fisicamente isso é coerente com o regime contínuo: depois do transitório os capacitores se comportam como circuitos abertos, não há queda em \(R_1\), e a fonte de corrente força \(I_0R_2\) em \(R_2\).

Definindo as condições iniciais líquidas \(a = v_{10} - I_0R_2\) e \(b = \dfrac{v_{20} - v_{10}}{R_1C_1}\), a solução sai direto pelas fórmulas do regime correspondente. No caso subamortecido, por exemplo:

\[ v_1(t) = I_0 R_2 + e^{-\alpha t}\!\left[a\cos(\omega_d t) + \frac{\alpha a + b}{\omega_d}\,\mathrm{sen}(\omega_d t)\right]H(t) \]

O procedimento é o mesmo para os regimes superamortecido e crítico — apenas muda a forma da parcela homogênea.

O que este exemplo ensina — o ponto central não é decorar a EDO final. É reconhecer a sequência: escolher uma variável de estado, escrever Kirchhoff, eliminar a variável auxiliar, identificar \(\alpha\) e \(\omega_0\), calcular as duas condições iniciais e somente então escolher a forma temporal adequada.
0.11

Método clássico no tempo × método por Laplace

O procedimento temporal tradicional para uma EDO linear não homogênea é:

1

Resolver a equação homogênea e encontrar \(x_h(t)\).

2

Obter uma solução particular \(x_p(t)\).

3

Somar: \(x = x_h + x_p\).

4

Usar as condições iniciais para determinar as constantes livres.

A transformada de Laplace reorganiza essas etapas. Em vez de procurar separadamente \(x_h\) e \(x_p\) e depois ajustar constantes, transformamos a EDO inteira de uma vez. As condições iniciais entram automaticamente, pelos termos de borda das transformadas das derivadas.

Transformação das derivadas e incorporação das condições iniciais

Se \(X(s) = \mathcal{L}\{x(t)\}\), a transformada unilateral da primeira derivada é \(\mathcal{L}\{\dot x(t)\} = sX(s) - x(0^-)\). Aplicando a propriedade novamente:

\[ \mathcal{L}\{\ddot x(t)\} = s\,\mathcal{L}\{\dot x(t)\} - \dot x(0^-) = s\big[sX(s) - x(0^-)\big] - \dot x(0^-) = s^2 X(s) - s\,x(0^-) - \dot x(0^-) \]

E para ordem \(n\):

\[ \mathcal{L}\{x^{(n)}(t)\} = s^n X(s) - s^{n-1}x(0^-) - s^{n-2}\dot x(0^-) - \cdots - x^{(n-1)}(0^-) \]

A demonstração dessas fórmulas — via integração por partes — está no módulo 01.

Transformação de uma EDO de ordem \(n\)

Considere \(x^{(n)} + a_1 x^{(n-1)} + \cdots + a_{n-1}\dot x + a_n x = b_0\,u(t)\), com \(x(0^-)=\xi_0\), \(\dot x(0^-)=\xi_1\), …, \(x^{(n-1)}(0^-)=\xi_{n-1}\).

Aplicando \(\mathcal{L}\) termo a termo e agrupando tudo que contém \(X(s)\):

\[ \big(s^n + a_1 s^{n-1} + \cdots + a_{n-1}s + a_n\big)X(s) = b_0\,U(s) + P_{\mathrm{ci}}(s) \]

em que \(P_{\mathrm{ci}}(s)\) reúne somente as contribuições das condições iniciais. Isolando \(X(s)\):

\[ X(s) = \underbrace{\frac{b_0\,U(s)}{D(s)}}_{\text{excitação externa}} + \underbrace{\frac{P_{\mathrm{ci}}(s)}{D(s)}}_{\text{estado inicial}}, \qquad D(s) = s^n + a_1 s^{n-1} + \cdots + a_n \]
A decomposição evidencia duas origens diferentes para a resposta: a excitação externa e a energia/estado existente antes de \(t=0\). E note que \(D(s)\) é exatamente o polinômio característico da seção 0.3 — com \(\lambda\) trocado por \(s\). Ao antitransformar \(X(s)\), a fatoração de \(D(s)\) reproduz exatamente as mesmas formas temporais encontradas pela equação característica. Essa é a razão pela qual as duas abordagens não podem discordar.

Teste · Questão 8PVI de segunda ordem no domínio \(s\) T2/2019 — Q1

A equação diferencial que descreve o comportamento livre de um circuito de segunda ordem é

\[ \ddot v(t) + 5\dot v(t) + 2v(t) = 0 \]

Sabendo-se que \(v(0^-) = 1\;\mathrm{V}\) e \(\dot v(0^-) = 20\;\mathrm{V/s}\), a transformada de Laplace de \(v(t)\) é igual a:

  • \(\dfrac{s+25}{s^2+5s+2}\)
  • \(\dfrac{s-5}{s^2-5s+2}\)
  • \(\dfrac{s+25}{s^2-5s-2}\)
  • \(\dfrac{s+1}{s^2+s+1}\)
  • \(\dfrac{s+5}{s^2+5s+2}\)
01
O que significa dizer que o circuito é de segunda ordem

A maior derivada é \(\ddot v\), portanto a EDO é de segunda ordem. Em circuitos, isso normalmente está associado a dois graus de liberdade de armazenamento de energia — por exemplo um indutor e um capacitor. São necessárias duas condições iniciais independentes para determinar completamente a trajetória temporal.

Uma realização possível é um RLC série em resposta natural. Seja \(v(t)=v_C(t)\). Pela LKT, \(v_R + v_L + v_C = 0\). Como a corrente de ramo é \(i(t)=C\dot v_C(t)\), temos \(v_R = Ri = RC\dot v\) e \(v_L = L\dot i = LC\ddot v\), logo \(LC\ddot v + RC\dot v + v = 0\). Dividindo por \(LC\):

\[ \ddot v + \frac{R}{L}\dot v + \frac{1}{LC}v = 0 \]

Portanto a EDO do enunciado pode representar um RLC com \(R/L = 5\) e \(1/(LC) = 2\) — por exemplo \(L=1\,\mathrm{H}\), \(R=5\,\Omega\), \(C=0{,}5\,\mathrm{F}\).

02
Resolver primeiro no domínio do tempo (para comparar depois)

Procurando \(v_h(t)=e^{rt}\), então \(\dot v_h = re^{rt}\) e \(\ddot v_h = r^2 e^{rt}\). Substituindo na EDO e cancelando \(e^{rt}\ne 0\):

\[ r^2 + 5r + 2 = 0 \;\Longrightarrow\; r_{1,2} = \frac{-5\pm\sqrt{25-8}}{2} = \frac{-5\pm\sqrt{17}}{2} \]

As duas raízes são reais, distintas e negativas — resposta superamortecida, com dois modos exponenciais decrescentes: \(v(t) = C_1 e^{r_1 t} + C_2 e^{r_2 t}\).

03
Aplicar as duas condições iniciais

Em \(t=0^+\): \(v(0^+) = C_1 + C_2 = 1\). Derivando, \(\dot v(t) = r_1C_1e^{r_1t} + r_2C_2e^{r_2t}\), logo \(\dot v(0^+) = r_1C_1 + r_2C_2 = 20\).

Do primeiro vínculo, \(C_2 = 1 - C_1\). Substituindo no segundo, \((r_1-r_2)C_1 = 20 - r_2\). Como \(r_1 - r_2 = \sqrt{17}\) e \(20 - r_2 = 20 + \frac{5+\sqrt{17}}{2} = \frac{45+\sqrt{17}}{2}\):

\[ C_1 = \frac{45+\sqrt{17}}{2\sqrt{17}}, \qquad C_2 = 1 - C_1 = \frac{\sqrt{17}-45}{2\sqrt{17}} \]
\[ v(t) = \frac{45+\sqrt{17}}{2\sqrt{17}}\,e^{\frac{-5+\sqrt{17}}{2}t} + \frac{\sqrt{17}-45}{2\sqrt{17}}\,e^{\frac{-5-\sqrt{17}}{2}t} \]

Os coeficientes têm sinais opostos porque a derivada inicial é fortemente positiva, mesmo que os dois modos individuais sejam decrescentes.

04
Conferir a solução temporal

Como cada raiz satisfaz \(r_k^2 + 5r_k + 2 = 0\), cada termo \(C_k e^{r_k t}\) satisfaz \(\ddot v_k + 5\dot v_k + 2v_k = C_k(r_k^2+5r_k+2)e^{r_kt} = 0\). Pela linearidade, a soma também satisfaz a EDO. Além disso \(C_1+C_2=1\) e \(r_1C_1+r_2C_2=20\) — as duas condições iniciais também são obedecidas.

05
Resolver agora por transformada de Laplace

Usando \(\mathcal{L}\{\dot v\} = sV(s)-v(0^-)\) e \(\mathcal{L}\{\ddot v\} = s^2V(s)-s\,v(0^-)-\dot v(0^-)\), e aplicando termo a termo:

\[ \big[s^2V - s(1) - 20\big] + 5\big[sV - 1\big] + 2V = 0 \]
\[ s^2V - s - 20 + 5sV - 5 + 2V = 0 \;\Longrightarrow\; (s^2+5s+2)V(s) - s - 25 = 0 \]
\[ V(s) = \frac{s+25}{s^2+5s+2} \]
06
Mostrar que Laplace contém os mesmos dois modos

O denominador fatora como \(s^2+5s+2 = (s-r_1)(s-r_2)\), com os mesmos \(r_1\) e \(r_2\) encontrados pela equação característica temporal. Uma decomposição em frações parciais gera exatamente \(\dfrac{C_1}{s-r_1} + \dfrac{C_2}{s-r_2}\), cuja antitransformada é a solução temporal obtida antes.

Ideia-chave — a transformada de Laplace não cria uma dinâmica diferente: ela apenas converte a EDO e as condições iniciais em álgebra no domínio \(s\). O polinômio do denominador é o polinômio característico.
Resposta: alternativa (a)
Teste · Questão 11EDO homogênea com condições iniciais T1/2022 — Q2

Considere a equação diferencial

\[ \ddot v(t) - \dot v(t) - 2v(t) = 0 \]

com condições iniciais \(v(0^-) = 1\) e \(\dot v(0^-) = 0\). A transformada de Laplace \(V(s)\) de \(v(t)\) é:

  • \(\dfrac{s-1}{s^2-s-2}\)
  • \(\dfrac{s}{s^2-2}\)
  • \(s^2-s-1\)
  • \(s\,e^{-2s}\)
  • \(-\dfrac{1}{s^2-s}\)
01
Transformar cada derivada

As fórmulas necessárias são \(\mathcal{L}\{\dot v\} = sV - v(0^-)\) e \(\mathcal{L}\{\ddot v\} = s^2V - s\,v(0^-) - \dot v(0^-)\). Substituindo as condições iniciais dadas:

\[ \mathcal{L}\{\dot v\} = sV - 1, \qquad \mathcal{L}\{\ddot v\} = s^2 V - s \]
02
Inserir na EDO e agrupar
\[ (s^2V - s) - (sV - 1) - 2V = 0 \]

Abrindo o segundo parêntese — atenção ao sinal, o \(-1\) vira \(+1\):

\[ s^2V - s - sV + 1 - 2V = 0 \;\Longrightarrow\; (s^2-s-2)V(s) - s + 1 = 0 \]
\[ V(s) = \frac{s-1}{s^2-s-2} \]
03
Conferência da condição inicial

Como \(V(s)\) é estritamente própria e não há impulso na origem, \(\displaystyle\lim_{s\to\infty} sV(s) = 1\) — coincidindo com \(v(0^-)=1\). É o Teorema do Valor Inicial servindo de checagem rápida (veja o apêndice sobre o TVI).

Dissertativa · Questão 2Sistema de EDOs e antitransformação P1/2018 — 1ª Questão

Considere o problema de valor inicial

\[ \begin{cases} \dot i_1(t) + i_1(t) - i_2(t) = 5, \\[4pt] 2\dot i_2(t) - i_1(t) + 3i_2(t) = 0, \end{cases} \qquad i_1(0^-) = i_2(0^-) = 1\;\mathrm{A} \]

(a) Obtenha \(I_2(s)\).   (b) Obtenha \(i_2(t)\) a partir de \(I_2(s)\) do item anterior.   (d) Para \(I_2(s) = \dfrac{s^2+s-2}{s^2+s+1}\), obtenha \(i_2(t)\) para \(t \ge 0\).

01
(a) Transformar o sistema de EDOs

Para a primeira equação, \(\mathcal{L}\{\dot i_1\} = sI_1 - 1\). Como o \(5\) é aplicado para \(t \ge 0\), \(\mathcal{L}\{5\} = 5/s\). Logo:

\[ (sI_1 - 1) + I_1 - I_2 = \frac{5}{s} \;\Longrightarrow\; (s+1)I_1 - I_2 = 1 + \frac{5}{s} \]

Para a segunda, \(2(sI_2 - 1) - I_1 + 3I_2 = 0\), portanto \(-I_1 + (2s+3)I_2 = 2\). O sistema algébrico é:

\[ \begin{bmatrix} s+1 & -1 \\ -1 & 2s+3\end{bmatrix}\begin{bmatrix} I_1 \\ I_2\end{bmatrix} = \begin{bmatrix} 1+5/s \\ 2\end{bmatrix} \]
02
(a) Isolar I₂(s) por Cramer

O determinante é \(D(s) = (s+1)(2s+3) - 1 = 2s^2+5s+2 = (2s+1)(s+2)\). Pela regra de Cramer, o numerador vale \(2(s+1) + 1 + \dfrac{5}{s} = 2s+3+\dfrac{5}{s} = \dfrac{2s^2+3s+5}{s}\). Assim:

\[ I_2(s) = \frac{2s^2+3s+5}{s\,(2s+1)(s+2)} \]
03
(b) Por que podemos usar resíduos simples?

Duas propriedades diferentes, que costumam ser confundidas:

1. O numerador tem grau 2 e o denominador grau 3 — logo \(I_2(s)\) é estritamente própria. Isso garante que não existe parte polinomial em \(s\) antes das frações parciais.

2. Os polos são \(0,\,-\tfrac12,\,-2\) e são distintos — logo são polos simples. É essa segunda propriedade que permite calcular cada coeficiente por \(R_k = \lim_{s\to p_k}(s-p_k)I_2(s)\).

Escrevendo a expansão na forma normalizada pelos polos: \(I_2(s) = \dfrac{A}{s} + \dfrac{B}{s+1/2} + \dfrac{C}{s+2}\).

04
(b) Calcular os três resíduos

Para \(p_1=0\): \(A = \left.\dfrac{2s^2+3s+5}{(2s+1)(s+2)}\right|_{s=0} = \dfrac{5}{2}\).

Para \(p_2=-1/2\), note que \(2s+1 = 2\left(s+\tfrac12\right)\), então o fator 2 sai para o denominador:

\[ B = \left.\frac{2s^2+3s+5}{2s(s+2)}\right|_{s=-1/2} = \frac{4}{-3/2} = -\frac{8}{3} \]

Para \(p_3=-2\): \(C = \left.\dfrac{2s^2+3s+5}{s(2s+1)}\right|_{s=-2} = \dfrac{7}{6}\). Portanto:

\[ I_2(s) = \frac{5/2}{s} - \frac{8/3}{s+1/2} + \frac{7/6}{s+2} \]
\[ i_2(t) = \left(\frac{5}{2} - \frac{8}{3}e^{-t/2} + \frac{7}{6}e^{-2t}\right)H(t) \]
05
(b) Conferência da condição inicial

Em \(t=0^+\): \(i_2(0^+) = \dfrac52 - \dfrac83 + \dfrac76 = \dfrac{15-16+7}{6} = 1\) — exatamente a condição inicial dada.

06
(d) Agora com uma função NÃO estritamente própria

Com \(I_2(s) = \dfrac{s^2+s-2}{s^2+s+1}\), os graus são iguais — existe uma parcela direta:

\[ I_2(s) = 1 - \frac{3}{s^2+s+1} \]

O termo \(1\) corresponde a \(\delta(t)\). No denominador restante, completa-se o quadrado:

\[ s^2+s+1 = \left(s+\tfrac12\right)^2 + \tfrac34 = \left(s+\tfrac12\right)^2 + \left(\tfrac{\sqrt3}{2}\right)^2 \]

Para casar com o par do seno, escrevemos \(3 = 2\sqrt3 \cdot \dfrac{\sqrt3}{2}\):

\[ \frac{3}{s^2+s+1} = 2\sqrt3\,\frac{\sqrt3/2}{(s+1/2)^2+(\sqrt3/2)^2} \]
\[ i_2(t) = \delta(t) - 2\sqrt3\,e^{-t/2}\,\mathrm{sen}\!\left(\frac{\sqrt3}{2}t\right)H(t) \]
Cuidado com a forma \(\tilde B/(2s+1)\) — se alguém escrever \(\dfrac{\tilde B}{2s+1}\), então \(\dfrac{\tilde B}{2s+1} = \dfrac{\tilde B/2}{s+1/2}\). Logo o resíduo verdadeiro no polo \(-1/2\) é \(\tilde B/2\). Na notação não normalizada aparecia \(\tilde B = -16/3\), enquanto na forma normalizada pelo polo o resíduo é \(B = -8/3\). São o mesmo resultado escrito de dois jeitos.
Comparando (b) e (d) — o item (b) evidencia a distinção entre função estritamente própria e polos simples; o item (d) mostra o que muda quando a função deixa de ser estritamente própria e passa a conter uma parcela impulsiva.
